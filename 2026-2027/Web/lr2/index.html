Завдання 1. Функція calculate() і блочна область видимості

Всередині функції calculate() оголошено змінну result. Всередині if оголошено іншу змінну result з тим самим ім'ям, але вона існує лише в блоці. Обидва значення виводяться у консоль.

Завдання 2. Секретне число

secretNumber - це залишок від ділення номера у журналі на 10. Введіть число від 0 до 9, щоб перевірити, чи вгадали.

Завдання 3. Сума двох чисел

Введіть ім'я та два числа. У консоль виводиться повідомлення про суму цих чисел через конкатенацію рядків.
